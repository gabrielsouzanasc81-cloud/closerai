# CloserAI 3.0

Plataforma SaaS de CRM e atendimento, desenvolvida com Next.js e Supabase e publicada na Vercel.

## Integrações

- **GitHub:** versionamento e revisão de código.
- **Vercel:** compilação e publicação.
- **Supabase:** autenticação e banco de dados PostgreSQL com RLS.
- **WhatsApp:** integração planejada, ainda não operacional.

## Segurança

Não inclua arquivos `.env`, chaves de serviço, tokens ou segredos no repositório. Configure variáveis de ambiente diretamente na Vercel.

## Status

Repositório inicializado. A importação e validação do código-fonte completo estão pendentes.
